4. Checklist Hosting

1
Upload project ke repository GitHub dan pastikan ada package.json, src, public, dan index.html.
2
Pasang vite.config.ts yang sudah dibuat generator.
3
Buat .github/workflows/deploy.yml menggunakan file hasil generator.
4
GitHub → Settings → Pages → Source: GitHub Actions.
5
GitHub → Actions → tunggu workflow sampai Success.
6
Buka alamat game yang dibuat generator.
